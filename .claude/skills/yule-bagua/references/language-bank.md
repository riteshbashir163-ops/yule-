# 语言银行：她的用词、句式与禁忌

写作时从这里取弹药。所有例句均出自原文语料，使用时化用变形，不逐字复读（同一篇里她的口头禅可以出现，但不要把本文档变成填空题）。

## 一、高频句式库

### 开场/立论
- "我还是那句话：……"（复读自己的旧观点，宣示立场一致性）
- "我敢百分之百肯定，……"
- "这么说吧，……"
- "别的不说，……"
- "由此可以合理推测，……"
- "我个人倾向于认为……"
- "先说……，再说……"

### 过渡/转场（全部口语，像说话喘气）
- "那好，我首先告诉大家……"
- "说回……"
- "到这里，……" / "写到这里，……"
- "话已至此，……"
- "插一句 / 另外插一句话，……"
- "顺便补充一下：……哈~"
- "好了，现在我们应该可以明白……了吧~"
- "其实每次……都会看到……"

### 科普
- "给并不太了解××的朋友做一下简单科普"
- "粗暴科普完……，我们再趁热一起回忆一下……"
- "给感兴趣的朋友科普一下，……哈"
- "不认识××的朋友或许会疑惑，××是谁？"

### 预设杠精与反驳
- "到这里呢，又有人要反驳了：……"
- "会有人说，……那么我的答案是：……"
- "也许有人会说，……那么我想说，……"
- "有人会说，不一定……啊，我就……。话是这么说，但……"
- "到这里，也许还有人认为……。那我来打个比方：……"

### 反问（当标点用）
- "凭什么？"
- "请问你是什么心情？"
- "什么感觉？是不是莫名其妙？"
- "难道……吗？"
- "……就可以理所当然被忽视吗？"
- "我们看到的一定是真实的吗？其实未必。"

### 邀请读者
- "大家可以去搜一搜……"
- "感兴趣的朋友可以去搜看看 / 一起来看一下 / 重新回去看一下"
- "大家还记不记得……"
- "如果大家还有印象的话，可以和我一起回忆一下……"
- "大家可以在评论区探讨"
- "请大家思考一下。"

### 判词/收束
- "……，仅此而已。"
- "一定会。"（独句成段）
- "够了，……"
- "……总有……的一天"
- "唯有热爱，可抵万难。"
- "×××你真的会做生意！" / "姐，你是真的姐！"
- "……的含金量还在上升！"
- "人生就是这样，第一次机会把握不住，第二次机会也会丢掉。"

### 现场直播感
- "打出这几个字的时候，我真的忍不住想笑"
- "文章写到这里点开微博，看到……"
- "现在正在打字的我……"
- "本来应该……再写这篇的，但是……让人有点迫不及待"

## 二、括号补刀模板（四类轮换）

- 吐槽型：（没懂，有什么好上的）（想不通这种热搜到底有什么好上的哈）
- 自嘲型：（力争一个××神算子称号）（我不行，我也不上，我只是觉得输的人菜！）
- 免责型：（网传数字）（这个数字是我瞎编的）（有误请指正）（据说）
- 预告型：（后面还要再提到这个知识点）（下一篇文章还会提到）

## 三、语气词规则

| 语气词 | 用途 | 例 |
| --- | --- | --- |
| 哈 / 哈~ | 阴阳缓冲、免责收尾 | "伤病和身体素质是两回事哈~""懂得都懂哈！" |
| 哦 / 哦~ | 假装天真的嘲讽 | "只是一个公司哦~公司是拿来干嘛的？赚钱的~" |
| 咯 | 摊手式讽刺 | "国球荣光不复当年咯" |
| 嘛 | 顺理成章式补刀 | "可不就是需要赚点钱嘛！" |
| 喽 | 轻快点名 | "当然是实力更强的中国喽" |
| 呀 | 对自己人的软 | "小鱼继续加油呀！" |
| ~ / ～ | 全文通用的态度波浪号 | 标题带~即预告嘲讽 |

规则：语气词只出现在句尾；对反派用哈/哦/咯/嘛，对自己人用呀/~；一段最多一两个，多了发嗲。

## 六、标点规则

- 引号：给被解构的词"升棺材"——"快乐乒乓""一路保胎""大女主逆袭""高情商"
- 破折号：**禁用**（运营者硬性要求，优先级最高）。语料里博主有"××——指……"的揭底习惯，此条不模仿：定义揭底改用冒号（"'高情商'：指在情感关系中游刃有余……的能力"），插入补充改用括号或逗号，强转折断句另起，并列串联用顿号。交稿前全文搜索"——"与"—"清零
- 感叹号：密度高但不连用（"！！"禁止）
- "？！"：震惊质问（"到底是些什么东西啊！？"）
- 省略号：抒情留白
- 顿号连列：报菜名式罗列（"队友、室友、好朋友、搭档"）

## 七、AI 味黑名单（命中任何一条立即改写）

1. **小标题、项目符号、加粗**出现在正文里——她的成稿是纯段落流
2. 段落长度均匀、每段都有漂亮的主题句
3. "总之/综上所述/总而言之/值得一提的是/不难发现/需要注意的是/首先让我们/接下来我们来看看"式书面过渡
4. 完美对称的排比（她的排比第三项常破格拐进吐槽）
5. 面面俱到、各打五十大板、"客观中立"——她永远偏心
6. 每个观点都配论据——她有些断言就是不讲理（"不仅不帅，而且会对手和看比赛的球迷内心黑人问号"）
7. 通篇零口语零跑题零插曲——要允许一处"插一句""说远了"
8. 形容词堆砌、四字词连用超过两个的华丽句
9. "赋能、闭环、维度、抓手、底层逻辑、情绪价值拉满"式互联网黑话浓度超标（"情绪价值"她用，但当名词平常用，不当口号）
10. 括号里写正经补充说明而不是人话弹幕
11. 结尾升华成中学作文（她的升华永远踩在具体的人和事上，最后一句常是狠话、白话或诗，不是口号套话）
12. 对不确定的事实用肯定句——她的规矩是打问号、标网传、自曝瞎编

## 八、允许并鼓励的不完美

- 口语化的不规范："real 市中心""有在看书""又双叒"
- 存疑标注当作人味："（2000？）""（有误请指正）"
- 情绪过载的自我承认："语无伦次""泄愤""无能狂怒"
- 结构的松弛：一段突然只有一句话；一个话题聊到一半先岔出去再拉回来（"说回……"）
- 不刻意制造错别字——她的笔误是真笔误，假造错字是另一种 AI 味
